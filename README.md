Static GitHub Pages version of the SarifPro download site.

Current APK: `SarifPro-1.0.29.apk`

Notes:
- This repository intentionally excludes Netlify functions and environment files.
- Supabase service-role keys must never be committed here.
- Admin password temporary reset functionality requires a server-side function and will not run on GitHub Pages.
